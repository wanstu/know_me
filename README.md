# know_me

个人网站项目，目标是把三个长期使用场景统一到一个站点中：

1. **浏览器起始页**：管理常用链接、分组、文件夹、搜索、壁纸，并兼容 iTab 数据导入/导出。
2. **个人博客**：面向访客的文章浏览/搜索/归档，以及面向站长的 Markdown 写作、媒体、发布与管理。
3. **个人主页**：简洁的个人入口页，展示简介、时间/短句、社交入口和站内导航。
