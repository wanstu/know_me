# 主页入口卡片的登录可见性

Know Me 首页「从这里进入（Explore）」的每张卡片可在「管理后台 → 站点设置 → 链接与项目 → 主页入口」分别设置显示条件：

- **始终显示（all）**：登录和未登录用户都看到。
- **仅登录显示（authenticated）**：只有有效登录会话的用户看到。
- **仅未登录显示（guest）**：仅未登录访客看到，例如登录入口。

既有保存的卡片缺少 visibility 字段时按 `all` 处理，升级后内容、排序、打开方式不会改变。新卡片默认为 `all`。其他项目卡片和起始页导航不受此选项影响。

原生 Go HTTP API 的 `GET /api/site` 对未登录访客移除「仅登录显示」的入口，并禁用共享缓存；登录管理员仍可编辑全部配置（包括「仅未登录显示」卡片），首页根据会话状态过滤。Next 兼容主页同样执行过滤。

**注意**：这是首页卡片的**显示条件**，不是目标 URL 的鉴权规则。受保护的后台、数据接口仍由其自身的登录验证控制。不要仅通过隐藏链接保护敏感页面。

验证建议：保持两个浏览器窗口（一个已登录、一个无痕未登录），分别确认三种条件；修改后保存，刷新检查排序、状态和数据保留。
