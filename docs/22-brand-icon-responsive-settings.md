# Site brand icon and responsive settings

## 站点图标

位置：后台 → 站点设置 → 主页内容 → 站点图标（左上角）。

- 支持复用媒体库中的图片、上传 PNG/WebP 等支持的图片格式、填写 `/media/...` 或 HTTPS 图片地址。
- 使用正方形图标，推荐透明背景；可预览并清除，清除恢复默认 K。
- Go Native 公共页面顶部、管理后台侧栏和浏览器标签页使用同一图标；该配置不改变个人头像。
- 数据保存在原有 `site.brandIconUrl` 中。旧站点没有该字段时使用默认 K，备份还原兼容。
- 图片失效时页面内图标恢复 K；不要依赖外链图片确保站点标识稳定。

## 设置布局

主页快捷标签和主页入口改用容器查询（CSS `container-type: inline-size`），基于后台**内容区域**而不是浏览器窗口宽度换行：

- 足够宽时使用两列字段排列。
- 内容区小于约 520px 时改为单列字段。
- 链接输入框、显示条件、上移/下移、删除和权限提醒在每个卡片内单独占位，避免不同控件相互覆盖。
- 页面访问权限卡片也跟随内容宽度切换 3 / 2 / 1 栏。

上线后建议分别在桌面窄窗口和移动端检查表单排版，特别是后台左侧导航栏占据宽度的情况。
