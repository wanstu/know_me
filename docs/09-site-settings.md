# 个人主页与站点设置

状态：基础完成  
日期：2026-09-18

后台入口：

~~~text
/admin/settings
~~~

## 可配置项

- 显示名称
- 一句话简介
- 个人介绍
- 头像
- GitHub
- 邮箱链接
- About 链接
- 短句
- 短句署名
- 个人主页背景
- 起始页背景
- 起始页默认搜索引擎
- 起始页是否允许未登录访问

起始页开启公开访问后，访客只会拿到 visibility=public 的分组和导航项。私有链接不会下发到浏览器。

## 背景 / 头像

支持：

- /media/... 媒体库地址
- https:// 外部图片地址

## 主题

支持：

- 跟随系统（auto）
- 深色（dark）
- 浅色（light）

主题应用于个人主页和浏览器起始页；博客继续保持以阅读为主的浅色排版，管理后台保持深色生产力界面。

## 后续可扩展

- 更细的主页入口卡片可视化管理
- 天气数据源

这些不阻塞当前站点使用。

## 验证

~~~powershell
npm run settings:smoke
~~~
