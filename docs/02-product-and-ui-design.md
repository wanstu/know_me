# 产品与 UI 设计

状态：Phase 2  
对应原型：prototype/index.html

## 1. 总体信息架构

~~~text
/
├─ /                    个人主页（公开）
├─ /start               浏览器起始页（默认私有）
├─ /blog                博客首页
│  ├─ /blog/search
│  ├─ /blog/archive
│  ├─ /blog/category/:slug
│  ├─ /blog/tag/:slug
│  └─ /blog/:slug
├─ /login               登录
└─ /admin               管理后台
   ├─ /admin/posts
   ├─ /admin/posts/new
   ├─ /admin/media
   ├─ /admin/navigation
   ├─ /admin/profile
   ├─ /admin/appearance
   ├─ /admin/import-export
   └─ /admin/settings
~~~

## 2. 视觉方向

关键词：

- 简约；
- 沉浸；
- 玻璃质感；
- 大留白；
- 轻边框；
- 少量高饱和强调色；
- 背景图只是氛围，不影响信息可读性。

统一设计 token：

- 圆角：12 / 16 / 24；
- 卡片边框：半透明 1px；
- 毛玻璃：backdrop-filter blur；
- 正文最大宽度：720~780px；
- 导航内容最大宽度：1280~1440px；
- 主操作强调色只使用一种；
- dark / light / auto 三种主题。

## 3. 个人主页

布局：

- 左侧：头像、名称、简介、社交入口；
- 右上：短句、时间；
- 右下：主要站内入口；
- 背景：自定义壁纸 + 遮罩；
- 小屏时自动变成单列。

用户第一次进入网站应该立即知道：

1. 这是谁的站；
2. 可以去哪里；
3. 博客在哪里。

## 4. 起始页

### 桌面布局

- 左侧细导航栏：分组；
- 中上：时间、日期；
- 中部：搜索框；
- 下部：卡片网格；
- 右上角：编辑、背景、设置、登录状态。

与参考图 1 的区别：

- 不使用持续占宽的右侧黑色大栏；
- 分组栏默认收窄，仅显示图标，hover 展开；
- 编辑功能只在编辑模式出现；
- 卡片统一尺寸系统，避免随意漂浮；
- 对背景增加遮罩，保证任何壁纸下都有可读性。

### 卡片尺寸

内部统一为：

- 1x1：普通入口；
- 2x1：横向大卡；
- 2x2：未来可放 widget。

iTab 映射：

- 2x2 → 内部 1x1；
- 2x4 → 内部 2x1。

导出时再映射回去，不强迫内部布局永久依赖 iTab 命名。

### 文件夹

文件夹卡片点击后打开浮层，不跳新页面。

浮层中：

- 4~8 个子入口；
- 支持再次排序；
- 支持“全部在新标签打开”（可关闭）；
- 显示文件夹名称。

## 5. 博客

博客页面不继续使用强玻璃化背景，否则长文阅读容易疲劳。

设计为：

- 顶部轻导航；
- 浅色/深色纯背景；
- 首页卡片适量玻璃效果；
- 文章正文区域接近文档阅读器；
- 代码块与引用块视觉明确；
- 右侧 TOC 仅宽屏出现；
- 小屏使用顶部“目录”按钮。

博客首页模块：

- 最新文章；
- 搜索；
- 标签；
- 分类；
- 归档入口。

## 6. 管理后台

后台使用“生产力 UI”而不是展示型 UI：

- 固定左侧栏；
- 顶部面包屑 + 全局命令入口；
- 主区使用普通卡片；
- 编辑器最大化内容空间。

文章编辑页：

~~~text
┌ 标题 / 状态 / 保存 / 发布 ┐
├──────────────┬─────────────┤
│ Markdown     │ Preview     │
│ Editor       │ Rendered    │
│              │             │
├──────────────┴─────────────┤
│ slug / tags / cover / SEO  │
└────────────────────────────┘
~~~

小屏改为“编辑 / 预览”切换。

## 7. 交互细节

### 起始页

- Ctrl/Cmd + K 聚焦搜索；
- 输入 / 可直接聚焦搜索；
- 编辑模式下拖拽；
- 非编辑模式禁止误拖动；
- 卡片右键 / 长按打开菜单；
- 新增入口按钮只在编辑模式出现。

### 博客编辑

- Ctrl/Cmd + S 保存草稿；
- 自动保存采用 debounce；
- 离开有未保存变更时提示；
- 粘贴图片可以直接上传；
- 发布前展示最终预览。

## 8. 原型说明

HTML 原型提供以下视图：

- 个人主页；
- 浏览器起始页；
- 博客列表；
- 博客详情；
- 管理后台；
- 文章编辑。

原型只用于确认信息架构、密度、风格与主要交互，不代表最终框架代码。
